# Bundled fonts

Both fonts are self-hosted under the SIL Open Font License 1.1
(https://openfontlicense.org). No font request leaves this origin.

- `Archivo-Variable.woff2` — Archivo variable (latin), weight 100–900,
  width axis 62%–125%. Used for display/headlines, condensed via the
  width axis. Copyright 2019 The Archivo Project Authors
  (https://github.com/Omnibus-Type/archivo).
- `Inter-Variable.woff2` — Inter variable (latin), weight 100–900. Used
  for all body, UI, and label text. Copyright 2016 The Inter Project
  Authors (https://github.com/rsms/inter).
