# FastShop capabilities

| Capability | Implementation and verification |
| --- | --- |
| Site editing and publication | Tenant-owned pages, blocks, menus, revisions and previews; content and route tests |
| Catalogue | Products, variants, collections, inventory and media; catalogue tests |
| Editorial content | Articles, categories, references and moderation; blog and review tests |
| Compliance | Claim wording, disease-term scanning and publication checks; compliance tests |
| Commerce | Quotes, hosted checkout, subscriptions, renewals and refunds; commerce tests |
| Merchant workspace | Orders, customers, integrations and reporting; Merchant Admin v2 browser acceptance |
| Storefront tracking | Consent-gated GA4, Google Ads, Meta and TikTok events; local browser interception tests |

Local fixtures demonstrate behaviour. Provider acceptance and merchant approval are separate launch requirements.
