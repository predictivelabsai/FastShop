# H24YOU Liquid M1

Build an opt-in server-rendered Liquid Metal pack, a separate preview fixture,
Home and Shop, using canonical editable block documents and site sandbox commerce.
Keep the legacy renderer byte-identical when the pack is absent.

References read: Lovable AGENTS.md, styles.css, content/site.ts, content/images.ts,
MetalPage.tsx, ShopPage.tsx, shared header, footer, top bars, review carousel,
HeroMedia and purchase helpers. Preserve the rose palette, pearl interludes,
1280px container, 88px section rhythm, Italiana headings, Quicksand body,
Fraunces accents, compact collection cards and responsive breakpoints.
FastShop DESIGN.md applies to the platform only.

Files: bounded theme resolver, block registry, isolated Liquid renderer and seed,
bootstrap hook, scoped CSS, progressive JS, self-hosted assets/fonts, tests and docs.
Acceptance: idempotent seed, canonical validation, 200 Home/Shop, preserved copy,
sandbox cart, opt-in regression coverage, full checks and browser captures at
375/768/1024/1440px with no overflow and working keyboard/reduced-motion controls.
Out of scope: M2/M3 pages, live payments, deployment, redesign and original source edits.
