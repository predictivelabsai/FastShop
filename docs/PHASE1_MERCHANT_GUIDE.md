# Merchant editing guide

Create a site at `/admin/sites`. Each site belongs to its own tenant. New sites start as private drafts.

Edit pages, shared settings and navigation in the workspace. Upload images through the media library and supply meaningful alternative text. Preview the draft at desktop and mobile sizes before publishing a revision.

Use the catalogue to manage product variants, prices, stock and collections. A product page can display purchase options once commerce is configured. The local simulator demonstrates checkout and subscription controls without taking payments.

Review legal policies, contact details, claims, source references and pending placeholders before launch. Benefit statements require compliant wording, an asterisk and a footer disclaimer. Compliance checks support review and do not replace merchant approval.

Use the go-live review to find missing configuration. Configure site-owned provider credentials and complete provider acceptance before enabling payments.
